# Streaming Movie Catalog Project

This beginner project compares movie listings on Netflix, Hulu, Prime Video, and Disney+ with Seaborn.

## Files in this folder

- `python mini project.py` — analysis code
- `MoviesOnStreamingPlatforms.csv` — dataset used by the script
- `project_report.md` — the step-by-step report
- `case_study.md` — project purpose, findings, and limits
- `01_...png` through `09_...png` — nine charts created by the script
- `requirements.txt` — Python packages
- `streaming-platforms.zip` — original Kaggle download archive

## Run it

1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Install packages: `python -m pip install -r requirements.txt`
4. Run: `python "python mini project.py"`
5. The nine chart images are saved in this same folder.

The Kaggle dataset is CC0 and is an older scraped snapshot. It shows movie availability and critics' Rotten Tomatoes scores, not viewing totals or revenue. Give the dataset creator credit in class materials.

Source: https://www.kaggle.com/datasets/ruchi798/movies-on-netflix-prime-video-hulu-and-disney
